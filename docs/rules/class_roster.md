# Class Roster

ASH has four core classes: [Fighter, Priest, Thief, and Wizard](05_classes_core.md). The following roster records the intended wider selection and the state of the existing handbook entries. An existing entry is a starting point, not a claim that it already matches the intended version. Classes marked **needed** do not yet have playable ASH rules.

The six [ability archetypes](06_classes_ability_archetypes.md)—Strong, Quick, Tough, Clever, Wise, and Charming—are separate classes inspired by Darkspace. Sage remains a distinct Intelligence-based class. Technology is optional.
